# Liber Daemonicum — superseded experiment

A grimoire of the agent stack: twelve daemons by rank and office, sixty-four
system states read as an oracle, a tree from intent to metal, and a sigil bench.

**Status: not part of the product.** Built as a twist on the Liber 488 format
before it was clear that Liber 488 is our own site. Kept because two ideas in it
earned their keep, and one did not:

- **Worth keeping:** the observation that a hexagram is six binary lines and so
  is a health check, which became the real I Ching module in `../../web`.
- **Worth keeping:** the grimoire's caution column — the thing a process table
  lacks. Any operational doc is better with "what it costs you when you call
  this badly" written next to the name.
- **Rejected:** the dark CRT visual treatment and the procedural hash-seals.
  They were decoration pretending to be meaning.

Static, no build step. Open `index.html`.
